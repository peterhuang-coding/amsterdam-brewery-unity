## 明确边界

- 学业只共享时间、人物与独立结局，不读写酿酒品质和配方。
- 冲浪只共享日历，拥有独立技巧、装备、照片和收藏；不产出经营现金、材料或 Meta。
- 城市节庆是规则容器，不为每个节庆复制一套小游戏。
- 二十二份小游戏策划是候选库，不是承诺全部开发的范围。
- 外部竞品和评论只支持“值得验证”的方向；功能价值最终由本项目试玩数据决定。

## 验收指标

| 假设 | 最低观察标准 |
| --- | --- |
| 未来需求能改变计划 | 玩家至少一次因订单修改采购、酿造、保留或销售安排 |
| 偏差能产生新路线 | 玩家能说出两个可行补救，并至少愿意尝试一个 |
| 批次流可理解 | 玩家能说明某批酒从哪里来、何时成熟、为什么能或不能交付 |
| 复玩来自策略 | 第二局开始前，玩家能说出一个想主动改变的策略 |
| 支线不挤占核心 | 玩家不会因强制支线而长时间无法进行酿造或销售 |
