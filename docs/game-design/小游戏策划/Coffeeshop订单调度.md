# Coffeeshop订单调度

## 定位

提供高流动性、高 Heat 的应急现金渠道。它与酒吧的区别是短订单、匿名客群、组合风险和快速周转。

## 准入与时长

特定课余窗口、地下 NPC 或夜间特殊事件开放，单次 60—120 秒。

## 输入

- 可用合法/灰色商品和实验产物；
- 匿名订单队列、交付时限和风险标签；
- 当前 Heat、联系人可信度和携带容量。

## 操作循环

1. **筛订单：** 订单只公开部分需求、利润和风险。
2. **组包：** 在有限容量内匹配标签，决定是否用替代品。
3. **排顺序：** 快速完成低价单，或拖延等待高价高风险单。
4. **交付结算：** 订单可能转成现金、情报、关系债务或检查事件。

## 随机性

订单池受活动、Heat 和地下关系影响。玩家可花一次情报资源揭示买家风险，但不能看穿全部身份。

## 结果层级

- 快速周转：现金少、风险低；
- 高价成交：现金高、Heat 上升；
- 替代交付：关系下降或加入追责事件；
- 拒单：无收益但移除潜在风险；
- 钓鱼事件：如果此前证据高，转入追捕或检查。

## 活动变体

节庆夜增加派对订单；检查周增加假买家；供应短缺提高替代品价值；博物馆夜出现收藏型小众订单。

## 系统边界

不使用真实受管制商品名称和交易流程，保持抽象标签。它不替代酒吧的品牌、客群学习和库存经营。

## MVP

六种订单、三种买家风险、四格组包、情报揭示和五级结果。P2，不进入首轮核心验证。
