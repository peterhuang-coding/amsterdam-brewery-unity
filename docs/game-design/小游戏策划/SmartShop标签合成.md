# SmartShop标签合成

## 定位

以 Heat 和不确定性换取违反常规的标签组合，是高方差 Build 的突变器，不是第二套酿酒。

## 准入与时长

拥有可合成的批次/材料、地下联系人和完整课余窗口时开放，单次 45—90 秒。

## 输入

- 一个基底物品或批次；
- 两个可选添加标签；
- 设备稳定度、Heat 和已知禁配信息；
- 当前地下订单与终局风险。

## 操作循环

1. **选择基底：** 决定牺牲哪个现有产物。
2. **选择突变方向：** 从效果、稀有度和风险不同的两到三条路径中 Draft。
3. **下注稳定度：** 投入时间、设备或关系降低负面标签概率。
4. **揭示结果：** 生成新标签组合，并明确其用途和检查风险。

## 随机性

结果池由输入标签决定，不允许完全无关的随机产物。玩家至少看到可能结果类别及风险区间。

## 结果层级

- 精准突变：获得目标稀有标签；
- 双刃结果：高价值与高风险并存；
- 偏向结果：用途改变但仍可交易；
- 不稳定结果：需要快速使用或处理；
- 失败回收：失去部分价值，保留一个基础材料。

## 活动变体

Pride 开放限定视觉标签；国王节偏向派对和批量；检查周提高非法来源权重；地下订单会临时改变高价值组合。

## 系统边界

Academic 不参与合成。SmartShop 不生成学业资源，也不能无成本洗白来源。

## MVP

六种基底标签、十二个突变结果、三档稳定投入和来源/Heat 联动。P2。
