# 关键学业挑战

## 定位

只在考试、Presentation 和 Group Project 等节点提供完整玩法，检验玩家此前是否为学业线留出准备空间。

## 准入与时长

由学校日历固定触发，单次 60—150 秒，每个七日 Run 只出现一到两个关键节点。

## 输入

- 准备进度、出勤、学业压力；
- 导师、同学、小组关系；
- 当天可用时间和临时事件；
- 该挑战自身的题型或表达要求。

## 操作循环

1. **选策略：** 稳妥覆盖、押重点、依赖队友或临场发挥。
2. **分配注意力：** 在有限时间内处理题目、结构、表达和突发追问。
3. **应对偏差：** 遇到陌生题、队友掉线或设备问题时选择止损方向。
4. **结算学业：** 生成成绩、关系变化与后续学校事件。

## 随机性

题型和突发情况来自学校 Seed，但会读取此前准备方向。高准备减少未知，不直接跳过挑战。

## 结果层级

- 优秀：学业压力下降并推进学校结局；
- 通过：维持当前状态；
- 勉强：需要补交或占用未来时段；
- 失败：进入补考、延期或关系修复路线；
- 社交成功：成绩一般但保住小组关系，形成另一条学业结局。

## 活动变体

考试周连续施压；博物馆夜可能让 Presentation 与晚间酒吧产生直接时间冲突；交通事件可能缩短准备阶段。

## 系统边界

成绩只影响学业与人物结局。它可以占用经营时间，但不能提供配方、原料或酒吧 Buff。

## MVP

Presentation 与考试两种模板、三阶段操作、五级结果和两个后续学业事件。
