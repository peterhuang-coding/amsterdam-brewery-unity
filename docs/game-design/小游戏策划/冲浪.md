# 冲浪

## 定位

完全独立的操作技巧与收藏玩法，用于表达角色的个人生活。它不服务学业、酿酒或酒吧经营。

## 准入与时长

```text
CanSurf = 有完整自由时段 && 当日浪况允许 && 玩家主动选择去海边
```

通常只在周末、假期、停课日或特殊长空窗开放，单次 90—180 秒。

## 输入

- 浪况、天气和海域难度；
- 冲浪技巧等级、冲浪板和服装；
- 本次挑战目标和收藏目标。

## 操作循环

1. **选浪区：** 安全岸边、中层浪区或危险深水。
2. **读节奏：** 观察浪峰、方向和连续组合窗口。
3. **执行动作：** 保持平衡、转向、加速和完成技巧链。
4. **选择返航：** 保存当前分数，或继续深入提高倍率。

## 随机性

浪型可预报，局部节奏和挑战组合按 Seed 变化。装备改变容错和动作风格，但不自动代替操作。

## 结果层级

- 安全完成：保存全部分数与普通收藏；
- 技巧完成：解锁动作熟练度和照片；
- 深水完成：高倍率与稀有外观收藏；
- 落水：结束本局并降低本次得分；
- 连续落水：只影响冲浪挑战记录，不影响次日生活。

## 活动变体

好天气开放特殊浪型；恶劣天气关闭或提供高难挑战；海边活动只改变冲浪挑战和收藏，不提供经营资源。

## 隔离边界

- 不产出论文、Focus、课程加成；
- 不产出酵母、酒花、库存或现金；
- 不解锁配方，也不影响酒吧客群；
- 失败不降低第二天上课或经营能力；
- 只共享活动日历和可用时间。

## MVP

三种浪区、四个基础动作、一个倍率系统、六件外观/照片收藏和完整独立结算。P2。
