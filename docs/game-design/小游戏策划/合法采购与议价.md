# 合法采购与议价

## 定位

核心是有限预算下的标签组合与供应关系，不是进入商店点击购买。

## 准入与时长

课间只开放快速采购；放学后开放完整采购；活动市场可开放特殊货架。单次 45—90 秒。

## 输入

- 现金、背包容量和剩余时间；
- 当前配方缺口与未来客群需求；
- 供应商货架、批量折扣和关系等级；
- 供应短缺、节庆限定与来源标签。

## 操作循环

1. **扫描货架：** 从有限商品中识别能补齐哪些配方标签。
2. **组购物篮：** 在容量与预算内组合原料、工具和替代品。
3. **议价：** 在现金折扣、赊账、批量购买、关系承诺中选一条。
4. **确认来源：** 接受 `legal`、临期、低品质或限量条件。

## 随机性

商品池由 Seed 和活动决定；价格区间公开，隐藏的是部分次级标签。供应商关系可以提高信息质量，但不保证出现指定商品。

## 结果层级

- 精准采购：补齐目标配方且保留现金；
- 替代采购：配方方向改变但仍可酿造；
- 赊账采购：保住库存，增加债务事件；
- 空手而归：保留现金和时间，可转入其他行动。

## 活动变体

国王节开放跳蚤市场，便宜但品质不稳；Pride 出现限定颜色和果香添加物；啤酒节前批发涨价；检查周提高合法货源的价值。

## 系统边界

合法采购不增加 Heat。隐藏标签只能带来配方不确定性，不能无预警产生犯罪证据。

## MVP

八种基础原料、三类供应商、背包容量、一次议价选择、价格和标签预览。
