# 城市路线与通勤

## 定位

把阿姆斯特丹的移动压缩成“时间—现金—风险—机会”的路线选择，不做开放世界步行模拟。

## 准入与时长

早晨上学、课间跨区、放学采购和活动日移动时触发，单次 30—60 秒。

## 输入

- 起点、目的地和剩余时间；
- 天气、交通封锁、活动拥挤度；
- 现金、自行车状态、车票状态、地区嫌疑；
- 途中可见的 2—4 个机会节点。

## 操作循环

1. **读图：** 查看三条抽象路线的时间、成本和主要风险。
2. **选交通：** 骑车、公共交通、步行或灰色路线。
3. **中途取舍：** 经过机会节点时决定绕路、停留或直达。
4. **抵达结算：** 剩余时间决定目标地点可执行的行动强度。

## 随机性与技巧

交通状态开局可见，途中只保留一个未知节点。玩家技巧体现在识别机会价值和及时止损，而非记地图。

## 结果层级

- 提前到达：获得完整行动窗口；
- 准时到达：正常进入目标玩法；
- 迟到：目标玩法减少一个阶段；
- 改道：失去原目标，但获得途中机会；
- 被检查：转入逃票或追捕结算。

## 活动变体

国王节封闭部分公共交通并增加街头节点；Pride 提高夜间拥挤和游客事件；暴雨提高骑车风险；检查周增加抽查线路。

## 系统边界

路线不产出任意资源，只决定“能否到达、剩多少时间、途中遇见什么”。

## MVP

三种交通方式、四类路线修正、八个机会节点、迟到对后续玩法的缩短规则。
