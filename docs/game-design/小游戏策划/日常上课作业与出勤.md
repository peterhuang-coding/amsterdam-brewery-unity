# 日常上课作业与出勤

## 定位

用极短决策表达留学生工作日义务和时间压力。普通上课不应每天变成重复操作关卡。

## 准入与时长

工作日课程时间自动出现，单次 10—30 秒；只有关键节点才进入完整学业挑战。

## 输入

- 当日课程、作业截止日期和出勤要求；
- 学业压力、准备进度、同学与导师关系；
- 当天采购缺口、酒吧准备需求和活动日程。

## 决策循环

1. **查看义务：** 明确今天最低要求和长期后果。
2. **选择投入：** 认真完成、最低限度、请人协作、延后或缺课。
3. **选择代价：** 消耗自由时间、关系承诺或积累学业压力。
4. **写回日程：** 根据选择开放或关闭课余窗口。

## 随机性

课程表和截止日开局公开。随机事件只改变老师要求、小组状况或临时任务，不得无预警直接判定挂科。

## 结果层级

- 充分完成：稳定学业线；
- 最低完成：保住出勤，压力不下降；
- 协作完成：节省时间，欠下同学承诺；
- 延期：释放当前窗口，未来任务加重；
- 缺课：获得完整行动时间，累积明确后果。

## 活动变体

考试周增加强制复习；Pride 可能早放；国王节停课；博物馆夜可能增加志愿任务，但只作用于学业和人物线。

## 系统边界

不检测原料、不修复啤酒、不提高市场预报，也不因高成绩直接增加经营收益。

## MVP

四类课程义务、五种投入选择、出勤/压力/关系三项状态和日程窗口联动。
