# 晚间酒吧服务

## 定位

它是经营线的兑现核心：把库存和菜单转成现金、反馈、关系与未来情报。乐趣来自排队调度和“卖给谁、拒绝谁、保留什么”。

## 准入与时长

工作日下班后固定进入；活动日可提前或延长。单次 120—240 秒。

## 输入

- 当晚菜单、库存和定价；
- 顾客 Deck、活动规则、服务能力；
- 当前 Heat、特殊订单、NPC 和设备状态。

## 操作循环

1. **读队列：** 顾客展示耐心、预算和部分偏好。
2. **匹配出酒：** 选择批次、份量和是否推荐替代品。
3. **管理节奏：** 在快速服务、解释故事、处理冲突和保留库存间切换。
4. **应对事件：** 醉客、检查、VIP、团体订单和库存见底改变队列规则。
5. **收尾反馈：** 记录哪些标签被接受，为未来预报和菜单提供信息。

## 随机性

顾客来自受活动、天气、价格和声望影响的牌组。玩家能看到客群范围，但具体顺序和特殊顾客未知。

## 结果层级

- 高效营业：现金和满意度平衡；
- 售罄爆发：收入高但提前关店、失去后续顾客；
- 精准小众：销量低但关系或品牌价值高；
- 服务失控：排队、错单和冲突增加；
- 检查事故：读取来源标签与许可证状态，不等同于随机扣钱。

## 活动变体

Pride 加入分享订单和团体客；国王节提高峰值与醉客；博物馆夜加入故事型顾客；考试周形成短时学生潮；检查周插入审查节点。

## 系统边界

操作重点是调度和判断，不做复杂第一人称倒酒模拟。顾客反馈只能改善经营预测，不给学业或冲浪加成。

## MVP

十个顾客原型、四个菜单槽、耐心队列、替代推荐、三个特殊事件和来源检查。
