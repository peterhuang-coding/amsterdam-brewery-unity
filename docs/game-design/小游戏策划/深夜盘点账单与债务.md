# 深夜盘点账单与债务

## 定位

每天的短结算与压力制造器，让现金用途形成真实取舍，而不是自动扣费后继续。

## 准入与时长

每晚营业结束后固定触发，单次 20—45 秒。

## 输入

- 当日现金、收入明细、损耗和库存；
- 房租、原料欠款、罚款、赊账和 NPC 承诺；
- 明后天活动与最低运营资金。

## 决策循环

1. **核对异常：** 找出损耗、错账、未完成订单和来源风险。
2. **支付排序：** 决定先付房租、供应商、罚款还是设备维修。
3. **处理缺口：** 延期、借款、卖库存、找 NPC 或接受债务事件。
4. **查看明日：** 将未解决问题写入次日事件 Deck。

## 随机性

账单数值可预测，随机性来自此前行为触发的额外费用和债权人事件。不能用随机账单无预警击穿 Run。

## 结果层级

- 全额支付：保持稳定；
- 优先支付：一项风险降低，另一项进入事件池；
- 延期：保留现金但提高后续成本；
- 紧急融资：立即存活，绑定未来承诺；
- 资产处置：卖设备或批次，改变 Build。

## 活动变体

节庆前需要预付摊位费；检查周可能产生许可证费用；供应短缺提高赊账成本；考试周减少可用赚钱时段。

## 系统边界

不做复杂会计模拟。所有数字必须对应可理解的具体义务和未来后果。

## MVP

四类账单、三种延期方式、最低运营资金提示和债务事件队列。
