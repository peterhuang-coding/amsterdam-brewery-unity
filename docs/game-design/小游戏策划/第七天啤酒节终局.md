# 第七天啤酒节终局

## 定位

读取整局 Build 的综合检查器。它不只看最高品质，而要检验玩家选择的经营路线是否自洽。

## 准入与时长

Day 7 固定触发，单次 180—300 秒；进入前允许最后一次库存、菜单和来源确认。

## 输入

- 参赛主打酒、备用酒和总供货量；
- 品质、风味、故事、来源和风险标签；
- 现金、品牌反馈、NPC 支持、Heat 与证据；
- 本局终局规则与评审/公众客群构成。

## 操作循环

1. **提交 Build：** 选择主打批次、摊位策略和公开品牌叙事。
2. **评审阶段：** 回答品质、风味与来源问题，决定展示哪些优势、隐藏哪些风险。
3. **公众阶段：** 用库存和服务节奏应对真实客流，防止只为评委准备而断货。
4. **危机阶段：** 根据 Heat、证据、设备和 NPC 承诺触发一个整局后果。
5. **结局阶段：** 生成经营、学业、地下路线和个人生活的并列结局。

## 随机性

终局题目在开局确定并公开主要评分维度；Day 7 只随机具体评委、客群顺序和一个危机事件，不临时更换胜利条件。

## 评分维度

| 维度 | 读取内容 |
|-|-|
| 品质 | 批次品质、稳定性和缺陷处理 |
| 市场 | 需求匹配、价格与供货量 |
| 品牌 | 故事标签、顾客反馈和 NPC 支持 |
| 合规 | 来源、许可证、Heat 和证据 |
| 韧性 | 设备、备用库存和危机应对 |

## 结果层级

- 合法精品酒厂；
- 社区酒馆与稳定生活；
- 高风险实验品牌；
- 地下传奇路线；
- 负债但保住配方与关系；
- 酒吧停牌但解锁新的下一局规则。

## 系统边界

冲浪成绩不参与啤酒节评分；学业只单独生成学校结局。终局允许多个不等价的成功，而不是单一总分排行榜。

## MVP

五项评分、两阶段经营挑战、一个危机阶段、六种结局模板和 Run 回顾时间线。
