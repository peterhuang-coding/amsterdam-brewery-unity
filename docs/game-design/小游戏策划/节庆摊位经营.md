# 节庆摊位经营

## 定位

把大型活动转成一次高峰经营挑战：库存有限、客流剧烈、规则特殊，区别于普通晚间酒吧。

## 准入与时长

Pride、国王节、啤酒节或其他大型活动占用完整行动块时开放，单次 90—180 秒。

## 输入

- 提前锁定的摊位位置、营业时间和费用；
- 携带库存、便携设备、菜单和人员帮助；
- 活动客群 Deck、天气、交通和许可证状态。

## 操作循环

1. **搭摊：** 在容量、展示、冷藏和服务速度之间分配有限槽位。
2. **应对客流波：** 根据舞台、游行或天气变化调整主推品。
3. **处理突发：** 缺货、设备问题、团体订单、检查或竞争摊位。
4. **决定收摊：** 提前保存利润，或延长营业争取最后客流并承担风险。

## 随机性

活动时间轴开局公开，客流峰值区间可见，具体顾客和突发事件未知。准备越充分，玩家拥有的应对选项越多。

## 结果层级

- 稳定盈利：现金、曝光和关系平衡；
- 爆发售罄：现金高但错失后续时段；
- 品牌成功：销量一般但完成活动目标；
- 运营失控：拥堵、损耗或差评；
- 检查事故：来源和许可证决定后果。

## 活动变体

Pride 强调分享、视觉和包容客群；国王节强调大批量、便携和价格波动；啤酒节强调品质、说明和同行竞争。

## 系统边界

摊位复用酒吧的顾客与库存规则，但加入容量、客流波和场地限制，不能只做“酒吧收入乘二”。

## MVP

一个通用摊位框架、三种活动规则包、四个搭摊槽、三波客流和五类突发事件。
