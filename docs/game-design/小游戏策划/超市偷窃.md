# 超市偷窃

## 定位

有限背包下的目标组合和嫌疑管理。玩法保持符号化，不复刻现实商店安防细节。

## 准入与时长

放学后或大型活动的自由窗口进入，单次 60—120 秒。

## 输入

- 商店区域、店员与监控的抽象警戒模式；
- 背包容量、时间、当前 Heat 与地区嫌疑；
- 商品价值、体积、用途、来源敏感度；
- 当日促销、拥挤和任务目标。

## 操作循环

1. **观察：** 花时间揭示部分警戒模式和高价值目标。
2. **装包：** 在容量中组合原料、工具、生活品和任务物品。
3. **管理嫌疑：** 每次动作改变嫌疑轨迹，玩家可提前撤退。
4. **离场：** 从普通出口、自助结账掩护或联系人接应中选择抽象方案。

## 随机性

商品与警戒模式随 Seed 变化；观察能减少未知。高价值物不会必然高风险，但会在后续搜查中形成更强证据。

## 结果层级

- 干净离场：获得 `stolen` 物品，无即时证据；
- 被记住：获得物品并增加地区嫌疑；
- 丢包逃离：保住人物安全，损失部分物品；
- 被拦截：物品没收并积累证据；
- 升级追捕：携带高价值目标时进入逃脱玩法。

## 活动变体

国王节提高人流和特殊商品；考试周出现学生生活品任务；检查周让地区嫌疑衰减更慢；供应短缺提高偷窃收益。

## 系统边界

偷窃不直接产现金。所有物品保留 `stolen` 来源，必须自用、销赃或洗白。

## MVP

三个区域、十二种物品、六格背包、嫌疑轨迹、三种离场方式和五级结果。
