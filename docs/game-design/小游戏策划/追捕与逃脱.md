# 追捕与逃脱

## 定位

它是灰色路线的风险结算器，用资源牺牲和路线判断改变 Build，而不是单纯反应 QTE。

## 准入与时长

逃票、偷窃、地下交易或检查事件越过阈值时触发，单次 30—75 秒。

## 输入

- 当前 Heat、证据、地区嫌疑；
- 携带物、现金、一次性工具和关系掩护；
- 已知出口、交通状态和剩余时间。

## 操作循环

1. **弃什么：** 丢赃物、销毁证据、付现金或消耗关系。
2. **走哪条路：** 在速度、隐蔽、时间和地区后果之间选择。
3. **最后手段：** 使用一次性技巧、伪装、合法票据或 NPC 掩护。
4. **接受新局面：** 失败不会结束 Run，而会锁区、加债务或迫使转合法路线。

## 随机性

追捕牌组由此前行为生成。系统公开主要威胁和两种可能升级，不允许毫无征兆地直接没收所有核心资产。

## 结果层级

- 完全脱离：保留物品，证据不增加；
- 牺牲脱离：丢弃部分物品或关系；
- 地区封锁：当日安全，但区域暂时不可进入；
- 正式处罚：罚款、没收、许可证风险；
- Build 转向：保住 Run，但地下路线暂时关闭。

## 活动变体

节庆拥挤提供掩护同时增加封路；暴雨减少路线；检查周提高证据权重；NPC 活动可能提供一次特殊出口。

## 系统边界

不加入战斗、武器或真实警务规避教学。失败必须留下可继续玩的替代路线。

## MVP

三阶段选择、六种牺牲资源、四种路线修正、五级失败和事件牌组联动。
