# 逃票

## 定位

在现金、时间和 Heat 之间主动下注。玩法保持抽象，不模拟现实逃票方法。

## 准入与时长

选择公共交通且不正常购票时进入，单次 30—60 秒。

## 输入

- 路线长度、拥挤度和检查强度；
- 现金、Heat、地区嫌疑；
- 是否携带赃物、非法批次或敏感任务物品；
- 已解锁的抽象策略卡。

## 操作循环

1. **读站：** 查看检查员类型、拥挤度和不完整的风险提示。
2. **选策略：** 使用“混入人群”“换线拖延”“关系掩护”等抽象卡。
3. **执行窗口：** 在上车、等待、补票止损和放弃路线之间选择。
4. **携带物结算：** 失败后果根据身上来源标签放大。

## 随机性

检查类型来自受 Heat 和活动影响的牌组。玩家总能提前看到至少一种风险信号，并拥有补票止损窗口。

## 结果层级

- 干净通过：节省车费，不留下证据；
- 可疑通过：节省车费，增加地区嫌疑；
- 补票止损：支付现金并损失时间；
- 被拦截：增加 Heat，可能暴露携带物；
- 事件升级：转入追捕与逃脱。

## 活动变体

大型节庆增加拥挤掩护，也提高线路封锁；检查周减少安全窗口；暴雨让放弃公共交通的代价更高。

## 系统边界

成功只节省成本，不直接奖励现金。不能通过背诵固定答案保证成功。

## MVP

三条路线、四张策略卡、三类检查员、四级结果、与携带物联动。
