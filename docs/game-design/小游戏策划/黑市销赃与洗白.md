# 黑市销赃与洗白

## 定位

它是灰色经济的兑现端，重点是延迟收益与清理证据，不需要做成操作型小游戏。

## 准入与时长

放学后、深夜或特定 NPC 出现时开放，单次 20—45 秒。

## 输入

- `stolen` 物品、非法批次和证据；
- 地下关系、当前 Heat、买家需求；
- 可用时间和藏匿容量。

## 决策循环

1. **匹配买家：** 每个买家只收部分标签，并给出现金、情报或关系报价。
2. **选择处理：** 快速销赃、等待高价、拆解、自用、交换情报或洗标签。
3. **支付代价：** 消耗时间、关系、现金或未来承诺。
4. **修改牌组：** 根据交易对象加入追债、勒索、掩护或稀有订单事件。

## 随机性

买家需求按 Seed 和活动变化；玩家提前知道下一次买家刷新的类别，但不知道完整报价。

## 结果层级

- 快速兑现：现金低、Heat 高；
- 高价等待：占藏匿容量，承担搜查；
- 成功洗白：转为 `laundered`，可进入正式经营；
- 情报交换：不拿现金，降低未来未知；
- 关系债务：当前收益高，后续必须履约。

## 活动变体

大型节庆提高派对物品需求；检查周压低报价并提高洗白价值；供应短缺让某些原料成为高价订单。

## 系统边界

洗白不会把低品质物品变成高品质，只改变来源风险。界面不得提供现实销赃流程细节。

## MVP

三类买家、五种处理方式、藏匿容量、`stolen → laundered` 转换和六张后续事件卡。
