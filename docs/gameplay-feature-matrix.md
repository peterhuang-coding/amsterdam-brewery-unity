## 当前最缺什么（产品判断）

1. **已有活动之间的因果**：新地图、自然三晚通关和核心可选活动已完成 P0 验收。当前重点转为把库存、人物约定与次日后果接紧；保留未实际走过的分支与新人体验边界，不把功能通过等同耐玩。
2. **完整成本与回报时机**：比较行动、现金、货物占用和未来收益；第三晚的奖励应能在现有三天内兑现或有明确收尾。先找到不同可行玩法，再调整经营压力，不强制每局跑完所有活动。
3. **城市与人物的辨识度**：用现有骑行、过河、搬货、音乐与邻里关系表达 Amsterdam 日常。当前不新增地点、小游戏或巴黎副本；先用实际试玩检验玩家能否说清选择、后果和再次游玩的理由。

研究依据与待验证方案：[2026-10-23 已有系统深化调研](research/2026-10-23-amsterdam-existing-systems-research.md)。本次为研究与优先级更新，尚未修改故事或经济规则。
