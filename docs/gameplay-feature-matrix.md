## 当前最缺什么（产品判断）

1. **完整可玩交付**：合格的加载组件还没有组成新地图游戏。先让显示、移动、存档与入口配合，走通三天主线和现有小游戏。
2. **清楚的行动后果**：新玩家应能理解去哪、为什么去、带回什么、如何影响今晚营业；需要试玩验证引导、反馈与风险收益，而不是假定已有确定缺陷。
3. **核心活动的重复吸引力**：优先观察玩家是否愿意再次夜探、经营和调整策略，再决定补动作、遭遇还是内容。巴黎短篇放在基础试玩稳定之后。
