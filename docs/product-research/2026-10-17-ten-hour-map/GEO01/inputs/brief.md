# GEO01 / D26 BGT import
Implement deterministic Python stdlib import_bgt.py, meaningful unittest test_bgt_import.py, and Node test_geo_data.cjs. Use actual small raw sample files for schema evidence and synthetic fixtures for corner cases. Do not Read entire generated data or paginate raw JSON repeatedly; inspect the provided sample-properties.md and use tests/code for bulk handling.
CLI: python3 import_bgt.py --manifest source-manifest.json --json geo-data.json --js geo-data.js --audit import-audit.json
Input manifest {bbox:[w,s,e,n],snapshot:string,complete:boolean,inputs:[{file,collection,sha256}],provider,url,license}. Each file is a complete GeoJSON FeatureCollection (one API page). Validate SHA and collection identity from manifest; implement only listed mapping waterdeel->water,pand->buildings,wegdeel->roads,overbruggingsdeel->bridges.
Emit schema exactly geo-interface.md; deterministic sorting by source ID and JSON bytes, identical repeated inputs dedup; no silent geometry repair. Validate date validity at snapshot from creation_date/termination_date and log exclusions by ID/reason in audit; historical feature versions/conflicting local IDs must not silently overwrite current geometry. Respect missing/null date fields without inventing dates. Error with clear reason for unsupported geometry, malformed/nonfinite rings, tampered SHA, invalid bbox or unknown layer. Genuine Polygon/MultiPolygon holes and source properties survive projection. Retain crossing-boundary geometry, don't clamp points.
Audit includes actual input counts, dedup/exclusions, output counts/rings/vertices, source sha, bbox, per-layer extents and explicit complete:false sample limitation. Python API convert(manifest,base_dir) returns data,audit for tests. Shared wrapper usable in browser global and require, no dependencies. Node tests check wrapper identity against JSON, source schema, finite values, real source-ID traceability/counts, not unsupported claim all Amsterdam.
Actual raw layers are public CC0 BGT. Full city raw files aren't sent (input size cap); parent reruns accepted CLI with the exact same manifest schema on full pages. This is source conversion code, not a completed game map. Final report includes only final outcomes of the four allowed commands, changed_files excludes reserved report; preserve early RED history in summary.
