# F29-MAP / MAP01: offline lightweight district compiler

Approved direction: recognizable city shape first; lightweight overview plus explicitly switched local districts. Raw BGT is offline input/reference, NOT browser payload. This is a new map product contract, not a retry of old lossless runtime. Implement ONLY this offline maker; no game/UI/navigation runtime changes.

Deliver Python CLI tools/geo/districts/build_districts.py and test_districts.py, README.md. Python3 + installed shapely/numpy only. Exact CLI: --source FILE --config FILE --out DIRECTORY. Full parent source uses same schema as real-pub-sample.json: layers.water/buildings/roads/bridges arrays, feature.polygons=[polygon[rings[[x,y],...]]], bounds=[minx,miny,maxx,maxy], properties. Do not assume GeoJSON features. Whole source is145703features/22.98Mpoints/514MB. Parent runs full source; worker fixture deliberately incomplete237KB.

Output contract, fixed for following runtime:
- manifest.json: schemaVersion1,mapVersion,projection,source{provider,license,snapshot,bbox,complete,inputSha256},overview{url,sha256,bytes,gzipBytes},districts[{id,name,bounds,url,sha256,bytes,gzipBytes,anchorIds}],travelLinks. Relative URLs. Deterministic sorted compact JSON, no timestamps; gzip with mtime0 for measured sizes. Hash final bytes. Do NOT upload/source-fetch.
- overview.json: schemaVersion1,mapVersion,bounds [0,0,width,height], shapes [{kind:'water'|'building'|'road'|'bridge',rings:[[[x,y],...],...]}], markers [{id,x,y,districtId}], travelLinks. World metre coordinates. Preserve recognizable actual canal/river/major block shapes, clip bbox. Simplify visual topology with4m tolerance; discard tiny decorative building/road shapes (e.g80m2), water threshold conservative(e.g10m2); bridges retain. Use geometry extraction robustly. Visual shapes are illustrative, not collision authority.
- districts/<id>.json: schemaVersion1,mapVersion,id,name,bounds,shapes in SAME world coordinate scheme with0.5m visual simplification; nav{origin:[minx,miny],cellSize,cols,rows,walkRuns:[[flatStart,length],...],bikeRuns:same}, anchors{<id>:{x,y,sourceX,sourceY,featureId}}, entrance:{x,y}. Row-major flat cell index=y*cols+x; runs sorted/nonoverlap, may span rows. All cells start blocked; only listed cells traversable. No route cache, no huge per-vertex JS objects. Each output includes practical attribution note, fictional venues and simplified map statement inREADME.
- audit.json: selected/output geometry/vertex counts, source invalid skipped counts, walk/bike cell counts, per-anchor displacement+reason, per-district connected component counts and required-anchor connectivity, raw/gzip sizes and budgets, determinism explanation. Missing/unreachable anchor is a clear error, not invented path; write diagnostic audit before nonzero exit.

Navigation is independently compiled offline, never inferred from simplified paint. For each district clip source geometry then union legal road surfaces and actual bridge decks. Roads exclude autosnelweg/autoweg/spoorbaan/OV-baan/baan voor vliegverkeer (including 'rijbaan ' prefix); bike additionally excludes voetpad/voetpad op trap/voetgangergebied/voetgangersgebied/ruiterpad. Only type_overbruggingsdeel='dek' bridge is surface. Water is blocked except deck; buildings blocked. Ignore negative-height roads; do not turn water into roads or treat stacked crossing as an inferred link. Invalid source geometry remains unchanged on disk; skip invalid polygons for nav with audit, visual may use clearly disclosed make_valid derivative.

Cell safety: mark a2m square navigable ONLY when its axis-aligned rectangle expanded0.4m on EVERY side is wholly covered by allowed surface (conservative radius). No checking centres alone, no diagonal corner leakage, no unverified long shortcuts. Use Shapely prepared/vectorized/chunked tests, bounded chunks; never loop every cell against every feature or generate all-feature pairs. Anchor may snap at most5m to a safe cell centre, and direct segment from original anchor with0.4m clearance must be covered; report original+new. If not possible, fail/report exact anchor rather than silently moving across river. Required anchors inside one district must share a4-neighbour walk component. entrance is first required anchor. Retain all safe disconnected cells but report; no silent deletion to fake connectivity. Bike connectivity need not connect walking-only doors; allow later dismount.

Budget target full overview gzip<=2MiB, district gzip<=8MiB; deterministic resource cap enforcement and errors. Config allows cellSize/tolerances/bounds so parent can diagnose data honestly. No precision-preservation requirement for visual/source attributes; only actual outline/crossings, local collision and provenance matter. No need full-surface topological equality or source vertex identity for visuals.

Tests: useful synthetic bridges-over-water vs pier, holes/buildings, excluded road classes/negativeheight, walking-only bike rule, finite/malformed config/source rejection, conservative expanded-cell safety, snapping across water rejected, disconnected required anchors fail, RLE bounds/determinism/hash/size, actual pub-sample build. Tests should not mirror implementation or skip unsupported behaviour. Fixtures can be inline inPython tests and write tempfile only. Generated sample outputs under sample-out/ are allowed generated material, not changed_files deliverables. No new deps/network/helpers. Keep scope to3owned files.
