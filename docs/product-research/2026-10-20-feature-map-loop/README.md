## 已批准设计及验收边界

大地图使用现有BGT范围的简化河网、街区、主路、关键桥梁及地点，作为位置和行程总览。局部图进入后才加载；第一版采用明确街区切换。视觉装饰、导航网络、局部碰撞分别处理。过河仍走桥/显式渡轮；跨区保留时间、携货、自行车和取消/恢复语义，不能免费跳过玩法。现有夜探/旅途为虚构小游戏场景，不冒充测绘街区。

禁止把复杂度降低解释为删掉主线必要地点或屏蔽原有小游戏；首版先打通一个真实往返，再拓展全部当前玩法入口。背景可合并简化，不要求保留所有地物的原始顶点；原数据不覆盖。大型生成物离线保存，浏览器只请求轻量总览和当前街区，不能仅切镜头仍加载全量。资源版本校验、加载失败可重试、已到达状态不伪造。

性能先设可测验收预算：总览压缩资源目标≤2MiB，单活动街区目标≤8MiB；加载和路线处理不得连续阻塞页面超过250ms。预算是否足够由实际生成与浏览器父验判定，不预报提速比例。几何安全、可达主线地点与经济存档行为优先，超预算如实报告。
