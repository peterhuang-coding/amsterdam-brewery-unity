# 现有经济的规则诊断

日期：2026-10-23。游戏基线：`720077c7f50748c6ed6318cc5b63b6643b5ea5b4`。本目录是研究证据，未修改生产规则。

从仓库根目录运行：

```sh
node docs/research/2026-10-23-evidence/economy-baseline.cjs
```

[脚本](economy-baseline.cjs)仅调用 `Reopening.createGame`、`Reopening.act` 和只读查询；没有直接注入现金、库存、关系或结局。记录的[七组输出](economy-baseline.json)绑定上述代码基线；未来调整规则后结果可以变化，不把这些数值固定为产品必须保持的单元测试。

## 策略与限制

- 每日只用一次准备行动：第一天酿黑啤，第二、三天酿艾尔；总计用 3/6 次行动。不做城市支线、夜探或人物邀请。
- 低品质组的三次酿造时机分数均为 0，得到品质 1；普通倒酒收杯进度为 0.5。高品质组得分均为 1、收杯进度为 0.72。
- 有货时按当前队列服务正确酒款；报价取 UI 可用的街坊价或符合品质与预算的 +4 档；缺货给水。
- 第一天房东赠酒、第二天拒绝网红、第三天选择检查试饮；正常推进营业、扣租及结局。升级对照仅第一晚选择指定升级，其余不升级。
- 脚本即时读取顾客和预算并作决定，省略玩家移动、阅读、找按钮、犹豫与反应失误。它不是自然浏览器通关或新人试玩，也没有证明最优解。

| 种子 / 参数 | 日1现金 | 日2现金 | 日3现金 | 累计满意 | 结果 |
|---|---:|---:|---:|---:|---|
| 2026，品质1，普通倒酒，无升级 | 91 | 140 | 173 | 25 | 获胜 |
| 42，同上 | 91 | 140 | 173 | 25 | 获胜 |
| 1，同上 | 91 | 140 | 173 | 25 | 获胜 |
| 2026，品质3，完美倒酒，无升级 | 113 | 206 | 279 | 25 | 获胜 |
| 2026，品质3，完美倒酒，驻唱角 | 113 | 224 | 313 | 25 | 获胜 |
| 2026，品质3，完美倒酒，陈酿桶 | 113 | 212 | 289 | 25 | 获胜 |
| 2026，品质3，完美倒酒，双酒头但仍串行 | 113 | 206 | 279 | 25 | 获胜 |

这证明存在对外出活动依赖很弱的获胜策略，不证明可选活动应强制化、全体玩家都觉得简单、所有种子相同，或双酒头对真实玩家无用。应结合行动机会、未来兑现日期和人物回应比较不同玩法，再观察新人实际选择。
