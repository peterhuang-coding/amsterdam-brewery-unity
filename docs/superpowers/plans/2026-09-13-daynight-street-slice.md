# 骑车逛城、花店与打烊后探险 Implementation Plan

**Goal:** 从已有自动探险切片交付一段可自由逛城/进店、骑车、配花、打烊后探险、次日反馈的生活循环。

**Architecture:** 保留既有 prep→night→summary→next/upgrade 三天结构，summary 是可逛夜城/出发探险的打烊时段；explore记录出发阶段，旧存档白天探险可正常完成。城市几何负责自行车真实位置/骑行/窄桥步行，规则层负责花束唯一库存、用途、夜间收益和次日反馈；UI显示同一城市的昼夜与地点入口。DLC仍是设计候选，不制作空壳购买入口。

**Tech Stack:** 原生JS/Canvas/CSS、Node行为检查、独立Playwright浏览器验收；不增加依赖或迁移Unity。

用户“你想想咋干干吧”授权实施此前设计的首个切片。沿用现有linked worktree codex/three-day-reopening，基线8415c27；工作区干净，78项基线检查通过。
