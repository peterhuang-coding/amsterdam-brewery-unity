# Tweede Kans: 三夜重开

用户已批准：以白天准备、夜晚酒吧为核心，制作三天完整试玩，两款酒、三个熟客、有限时间与库存、第三晚重新开业。当前实现基线为 GitHub 默认分支 12995e2。原实验版本保留到 legacy.html，默认 index.html 提供新体验。

用户进一步明确：希望是《潜水员戴夫》那样的白天行动、夜晚经营节奏，但更荒诞、更有黑色幽默。气质调整为运河城市的荒诞生存：房东催租还赊酒、网红拿曝光换库存、检查员制造手续。幽默必须带有可见经营后果，不能只换文案。白天增加一个可操作的 30 秒运河打捞（北岸冲浪路线），三个航道移动、看准时机打捞酒花或押金瓶，错抓单车残骸需付清运费。每晚一个暂停时间的两难事件，由明确成本/效果的二选一改变租金、库存、预算或耐心。

## 体验

玩家接手运河边的 Tweede Kans，三天后重开。每天两次准备：18 秒内完成三段酿造、帮 Bram 的咖啡店、去北岸运河限时打捞酒花或密封瓶、拜访 Lotte 约定留一杯黑啤。Marta 在店里作为第三位熟客，重视酒的品质。晚间需选择顾客、酒款、报价并看准时机收杯；日间库存和承诺改变晚间收益与翌日人物反应。

新手第一晚先接待 Marta，期间时钟在教学层暂停。每晚顾客按时间到来，有明确口味、预算、耐心。允许选择等待中的客人先服务。缺货可送水善后，早打烊需要内联确认。可随时暂停，页面不可见时自动暂停；读帮助、晚间事件或升级时不耗时间。首杯操作目标 60 秒内理解。

每天结算展示卖出杯数、收益、错失顾客、承诺结果。前两晚三选一设备：双酒头可以同时准备两杯；陈酿桶提升过夜酒价值；驻唱角延长耐心、增加小费但减少同时等候容量。第三晚显示营业结果、累计满意顾客与熟客记忆，并能以同一 seed 或新 seed 重玩。

现金目标 €100、至少 12 位满意顾客；单局内关系记录带来乐队与熟客反馈。结果允许部分达成，失败也能重玩。存档与旧版隔离，刷新恢复当前三天游戏（夜间、酿造、打捞恢复默认暂停），同 seed 的顾客和事件安排一致。

## 实现边界

不将旧 8000 行全局游戏继续叠加改造。保留旧版代码和原回归套件；新默认入口复用项目的生成图片、酒吧名称和人物联系，以小型纯 JS 规则模块驱动 DOM 与 Canvas 场景。没有新框架、包依赖或远端服务。双击 index.html 和静态 HTTP 均可运行。

## 视觉

主视角是一家可以看见变化的酒吧：瓶架库存、铜酒头、运河窗景、空/满座、暖色灯光与乐队。主色运河蓝 #173c49、瓶绿 #345c49、铜色 #ce8e4c、灯光黄 #f1cf8a、旧纸 #ece0bf、深木 #241c20。正文用系统中文字体，招牌以 Georgia 衬线字写 Tweede Kans，数据用等宽。保留足够大的文字和按钮，少量功能色，操作反馈集中在杯子和顾客。
