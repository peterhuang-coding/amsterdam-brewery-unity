## 可玩的范围

保留既有连续地图、自动/手动探索和经营回报。在三个夜晚轮换超市卸货、道路施工、夜店散场：实际碰撞通路或人群分布不同，同 Seed/日可复现，开局与地图都说明局势。

新增空瓶引诱：每趟三瓶，N / 按钮投向瞄准方向，范围有限且不穿墙。有限时间的声源吸引听得到的巡查/机器走过去；贴脸时仍有危险。声音、冷却和追查随暂停停止，随存档恢复。

新增拖动路障桶：R / 按钮靠近抓住，再移动拖桶，再按放下；降速、有距离/碰撞约束，不能隔墙抓桶或把桶推入墙。路障桶不属于背包战利品。放下的桶实际挡住人物通行和机器冲撞。地图中标记可拖动桶。

自动探索在夜店提供“空瓶引开后拿箱”与“摆桶挡路后绕行拿箱”，仍保留泡沫和钩取。自动策略通过同一 command/step 实际执行；动态障碍变化时重新寻路，不能瞬移、假装成功或读选项时消耗时间。

## 数据与接口

- 新探险 version=2，原经营存档版本不变。
- r.street = { situation, baits, lureCooldown, noise, barrels, dragging }。
- situation 为 delivery / works / closing，旧 version=1 迁移为 legacy，原局势与位置不突变。
- noise 为 null 或 { x, y, life }；barrels 为 {id,x,y} 数组；dragging 为 null 或桶 id。
- Backstage.streetInfo(r) 返回 {id,title,description,hint,walls}；每条 walls 是 x/y/w/h/kind，绘制与碰撞同源。
- Backstage.command(r,'lure',aim) 和 command(r,'drag')。现有 step/load/rewards/zone 等接口保留。
- 调查中的 actor.mode = investigate，仍使用已有 timer；全局 noise 提供声源。无声源时回巡逻。
- 旧存档继续完成旧夜探，下一晚才使用新局势；新状态校验拒绝非法数量、坐标、模式、桶 ID 与穿墙位置，迁移须写回嵌套探险状态。

## 验收

1. 三夜局势不同且可复现；实际路障改变可走区域，所有关键目的地及撤退口可达。
2. 空瓶消耗准确，声音改变敌人位置与行为，不隔墙投掷；追查期确实提供绕行窗口。
3. 手动与自动都能拖桶；桶停留在实际位置并中断机器冲撞，不能隔墙/隔空拖动。
4. 自动拿箱有多种真实路径，三种局势下均可走到选择或明确的可恢复结果。
5. 暂停、刷新、自动转手动与老存档继续均不丢货物、发现或家中资产。
6. 页面可看到局势、路障、声源与剩余空瓶；按钮与键盘说明匹配，手机宽度不横向溢出。
