# 地点深化：超市、夜店与骑车过桥

用户在上一轮具体提案后回复「你就做吧」，批准本轮实现。基线 d10778f；沿用 three-day-slice 隔离工作区与本机 18767 入口。

## 玩家体验

白天在市场观察卸货、咖啡馆打听夜店，免费记下可操作线索；晚上在连续地图中进入超市货架区、冷库与卸货通道，选择不同货物与出口；夜店音乐周期影响守卫察觉，散场人群改变路线。操作仍是移动、钩取、引声、拖桶、互动，不新增独立小游戏。读选择时整个模拟暂停，等待节拍必须是明确的主动选择。次日地图/店内出现与实际行为相符的反馈。

## 夜探规则与接口

- 新夜探 version 3；旧 1/2 局保持原有几何与规则，下一趟才启用新地点，迁移不能改变旧位置/物品。
- `B.create(seed,day,kit,discoveries,context={clues:[]})`，clues 为 market / club；提供真实入口/节拍知识，不强制白天准备。
- market 内部至少三个可辨认子空间，两个可通行路径，普通货物实际放置于内；互动开卸货捷径，发现 `market-shortcut` 跨日保留。
- club 音乐/静音周期以 run.time 推导；音乐时警觉范围缩小，近距离始终危险，静音时恢复；人群位置随周期改变，移动遵循可通行几何。空瓶在相同环境规则下可听见/被掩盖，UI 提示当前条件。
- 自动探索在 market 提供货架/冷库/开捷径选择；在 club 保留原取箱策略，并增加等音乐再穿过人群的选择。实际走路、等待、用工具，禁止直接发奖励或传送。中途存档可恢复。
- `B.locationInfo(run)` 为 UI 返回 `{enabled, market:{...}, club:{...}, rooms:[], walls:[], door:...}`；具体字段实现前由核心执行者确定并通知集成者。场景与碰撞使用同源几何。
- `B.rewards(run).outcomes` 使用枚举数组 `market-salvaged`, `market-shortcut`, `club-backstage`，只记录真实触发；原 reward 字段保留。discovered 新增 `market-shortcut`。

## 白天与次日

life 新增 clues 数组（market / club），旧存档缺字段迁移为空；scout 操作仅 prep 免费，每处每日一次，按钮在实际地点页面。线索夜探复制快照，次日重置当日线索。returnExplore 把实际 outcomes 写入 morning，最多八条；market-shortcut 为永久发现，下趟几何开放，地点文案反映变化。

## 自行车

现有较宽桥骑行；窄桥/渡轮自动推行，车保持在玩家身边，到可骑区域自动恢复。B 主动停放或进店才留下车。推行状态可保存，旧 parked/mounted 数据兼容；不穿水、不穿建筑。UI 和地图姿势区分骑行、推行和步行。

## 验收

新增行为测试先失败后通过：内部路线可达、环境周期真实改变察觉/人群、选择冻结时间、等音乐与所有取箱方式可退出、任何中途状态可恢复、旧夜探几何不变、白天线索与次日反馈闭环、全部桥双向随车通过。全量 Node 回归、独立浏览器完整流程、390px 布局/控制台检查。用户浏览器存档不重置。自主规格与质量审查通过后提交并 push；Notion 与 Hub 更新实际证据。原长期耐玩性仍由玩家判断。
