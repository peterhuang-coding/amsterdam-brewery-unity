# Tweede Kans · 三天重开试玩

默认 `index.html` 是新的三天经营切片。白天出去折腾、晚上开店，黑色幽默通过真实成本和后果发生：房东喝酒抵租，网红用免费样品换预算更高的客流，检查员的表格也有处理费。

## 城市背面探险（2026-09-13）

欢迎页点「先去城市背面探险」，或在白天地图/酒馆/市场/北岸的探险卡片出发。每天一次，占一次准备机会；先选长钩绳、搬货背架或泡沫工具，分别改变射程、容量、步速或泡沫恢复速度。原三天经营、旧打捞和其他白天行动仍可使用。

一张连续的 2200×1400 行动地图连接超市后场、红灯运河街、NO SIGNAL 夜店、失物分拣场和温室。走动、钩取、泡沫、闪避在所有区域使用同一规则。滚桶、机器冲撞、巡查者、人群和叼零件的鸟会改变取得物品的过程；相同种子/日/工具/输入可复现，种子与日期改变部分物资位置、运动方向及巡回初始条件。

默认使用 **自动探索 + 关键选择**：点击行动或按 `1 / 2 / 3`，角色会真正走到目的地、收集和使用工具；拿箱、交还 Noor、开温室前暂停等你决定。阅读选项时，人物、物品、冷却和倒计时全部暂停。地图下方可切换 `1× / 2×` 播放；途中可「停下来，重新选路」。容量不足时逐件选择放下什么。已交还的箱子不再显示成领取目标。

旧存档刷新后可点「切换自动探索」；新一趟默认启用。随时切换手动操作，切回自动时重新选路线，已有物品、发现与时间保留。未走完的自动目的地或待选事件随探险一起保存。以下为手动操作及两种模式共用规则：

- `WASD` / 方向键移动；鼠标瞄准，左键或 `J` 钩拉，右键或 `F` 泡沫；`Space` 朝瞄准方向闪避。鼠标离开画布后，纯键盘操作朝行走方向使用工具。
- 普通物资靠近自动装包；`E` 拿冷藏箱、与 Noor 交谈/交付、操作闸门和撤离。`Q` 朝瞄准方向扔下最后一件物品，腾出背包；被撞掉的东西可以追回。
- `M` 全图/跟随镜头；`P` / `Esc` 暂停；`H` 帮助。画面下方方向键可按住，工具和互动都有按钮。
- 180 秒收班。西南入口可随时安全撤回，保留全部背包；温室后门提供第二条安全回家路线。超时或受伤三次保留一半物品件数，主动轻装撤回放弃未交付背包；家中现金和库存不受影响。
- 虚构违禁品“月雾”装在夜店冷藏箱里，需主动拿取，占 3 格。交还红灯街的 Noor 得到 €14 跑腿费，她会在当晚作为顾客出现；带回箱子则会有打听箱子的人来店。箱子与啤酒、酒花严格分开，不增加酿造材料。
- 温室的维护拉杆可以近身操作或钩拉。实际进入后记录发现，下一天闸门仍打开，可以从后门回到酒馆屋顶。Noor 的经历和箱子处理结果也跨日保留。
- 归来页显示带回内容，点「回酒馆，收好这一趟」一次性入库。刷新保存正在进行的探险并先暂停；旧版三天存档自动补充探险字段，保留原进度。

当前是主玩法验证切片：区域地形固定，只有部分遭遇条件变化；成人题材通过街区、人物和虚构货物表达，尚无毒品使用系统、独立成人服务玩法或完整社会模拟。是否足够耐玩仍需玩家反复试玩判断。

## 三天闭环

白天先从酒吧门口进入城市主地图。六个地点通过运河桥与北岸渡轮连接：Tweede Kans、Lotte 的桥、Bram 咖啡馆、北岸码头、Albert Cuyp 市场、Chen 实验室。步行和逛地图免费，点地点自动寻路，到达后打开店铺面板，也可 WASD 自己走并按 E 进入。

每天两次准备：酿一批酒（€12、6 杯、三段工艺）、替 Bram 打工（赚 €18）、拜访 Lotte（答应留黑啤），或去北岸运河打捞（30 秒或 3 份有用收获）。酒花让下一批品质 +1，密封瓶补充 2 杯库存，单车扣 €2 清运费；捞不到东西也会消耗行动。酒花每批消耗一份。市场另售 €8 的收摊箱（2 杯艾尔 +1 杯黑啤、品质1），实验室售 €6 的两份试验酒花，二者都每天一次、占一次准备。

夜晚选择顾客、核对口味和预算、倒酒并及时收杯。开始倒酒立刻消耗一杯；等待太久、溢杯、错口味和超预算都有后果。无酒时可以送水善后。Lotte 在晚些时候到店；兑现留酒承诺后，下一晚乐队能改善耐心和小费。

每晚营业到第 35 秒会遇到一件暂停事件，阅读后选择：

| 日 | 麻烦 | 选择及代价 |
|---|---|---|
| 1 | 房东的液体押金 | 1 杯酒换租金 −€6；拒绝则租金 +€3 |
| 2 | 曝光量不能交房租 | 2 杯样品换未来 3 位客人预算 +€4；拒绝则这 3 位耐心 −4 秒 |
| 3 | 未发现问题的问题 | €10 手续费换等待及未来客人耐心 +12 秒；延期检查则租金 +€6 |

基础租金 €18，账单展示事件后的实际金额。提前打烊会错过未服务的顾客。前两晚可免费选一件设备：双酒头同时倒两杯；陈酿桶提升隔夜余酒收益；驻唱角增加耐心和小费，但少一个座位。第三晚目标：余额至少 €100、累计 12 位满意顾客。

## 操作与存档

- 城市地图：`WASD` / 方向键移动，`E` 进入附近地点，`M` 回地图；点击地图或六个地点按钮自动寻路；可切换全城 / 放大跟随视角。
- `A / D` 或左右方向键：打捞时换航道；`Space`：打捞、确认酿造、收杯。
- `1 / 2 / 3`：选顾客；`E`：开始倒酒。
- `P / Esc`：暂停；`H`：帮助。事件必须点击选项，不会因按 Esc 自动作出决定。
- 页面上的按钮涵盖全部操作，适配窄屏。
- 进度存于 `ab_reopening_v1`，包括酿造阶段内计时、城市位置与发现地点。刷新会停止未走完的路线，但保留位置；旧存档没有城市信息时，从酒吧门口开始。切到后台和刷新后会暂停，恢复后继续。
- 暂停菜单可以重开；结束页可以用相同顾客安排重试或换种子。
- 新入口与旧七天版存档键独立。无法读取或格式不符的试玩存档会提示并新开一局。

- `reopening-city.js`：城市地形、建筑碰撞、桥/渡轮通路、自动寻路、步行和独立地图存档验证。

新规则测试覆盖完整三天获胜与失败、资源消耗、留酒承诺、设备取舍、事件成本与暂停、打捞收益/失误/靠岸、种子确定性及非法存档。`test-phase-e.js` 单独验收旧版 Phase E 规则。

手动验收：进入打捞并捕获物品 → 酿一批 → 夜晚成功收杯 → 应对事件 → 刷新确认暂停恢复 → 结算选升级 → 走完第三晚 → 重开；同时检查窄屏按钮和控制台错误。

探险验收：默认入口选工具 → 自动选择目的地（或切换手动移动和钩取） → 夜店拿箱 → 红灯街交给 Noor → 温室开闸并发现后门 → 撤离结算入库 → 夜晚见到 Noor；另检查轻装撤回、超时、受伤、背包上限、鼠标随镜头瞄准和刷新暂停。自动测试验证规则，浏览器验收验证操作链，两者都不能替代玩家的趣味反馈。

本轮自动模式验证（2026-09-13）：9 项自动模式＋16 项探险＋40 项经营＋13 项城市检查通过。浏览器点击完成拿箱→Noor交还→温室→屋顶撤离，实际带回6杯艾尔、1酒花、€19；验证选择冻结、P暂停、刷新恢复、模式切换及390px无横向溢出。旧Phase E、Unity和直接file入口没有本轮验证。
