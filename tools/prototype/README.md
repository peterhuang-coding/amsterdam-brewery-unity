# Tweede Kans · 三天重开试玩

默认 `index.html` 是新的三天经营切片。白天出去折腾、晚上开店，黑色幽默通过真实成本和后果发生：房东喝酒抵租，网红用免费样品换预算更高的客流，检查员的表格也有处理费。

## 启动

仓库根目录运行：

```sh
python3 -m http.server 18767 --bind 127.0.0.1 -d tools/prototype
```

访问 http://127.0.0.1:18767/?seed=42 。无需依赖安装或构建，也能直接打开 `index.html`。相同种子和操作产生相同结果。

## 三天闭环

白天先从酒吧门口进入城市主地图。六个地点通过运河桥与北岸渡轮连接：Tweede Kans、Lotte 的桥、Bram 咖啡馆、北岸码头、Albert Cuyp 市场、Chen 实验室。步行和逛地图免费，点地点自动寻路，到达后打开店铺面板，也可 WASD 自己走并按 E 进入。

每天两次准备：酿一批酒（€12、6 杯、三段工艺）、替 Bram 打工（赚 €18）、拜访 Lotte（答应留黑啤），或去北岸运河打捞（30 秒或 3 份有用收获）。酒花让下一批品质 +1，密封瓶补充 2 杯库存，单车扣 €2 清运费；捞不到东西也会消耗行动。酒花每批消耗一份。市场另售 €8 的收摊箱（2 杯艾尔 +1 杯黑啤、品质1），实验室售 €6 的两份试验酒花，二者都每天一次、占一次准备。

夜晚选择顾客、核对口味和预算、倒酒并及时收杯。开始倒酒立刻消耗一杯；等待太久、溢杯、错口味和超预算都有后果。无酒时可以送水善后。Lotte 在晚些时候到店；兑现留酒承诺后，下一晚乐队能改善耐心和小费。

每晚营业到第 35 秒会遇到一件暂停事件，阅读后选择：

| 日 | 麻烦 | 选择及代价 |
|---|---|---|
| 1 | 房东的液体押金 | 1 杯酒换租金 −€6；拒绝则租金 +€3 |
| 2 | 曝光量不能交房租 | 2 杯样品换未来 3 位客人预算 +€4；拒绝则这 3 位耐心 −4 秒 |
| 3 | 未发现问题的问题 | €10 手续费换等待及未来客人耐心 +12 秒；延期检查则租金 +€6 |

基础租金 €18，账单展示事件后的实际金额。提前打烊会错过未服务的顾客。前两晚可免费选一件设备：双酒头同时倒两杯；陈酿桶提升隔夜余酒收益；驻唱角增加耐心和小费，但少一个座位。第三晚目标：余额至少 €100、累计 12 位满意顾客。

## 操作与存档

- 城市地图：`WASD` / 方向键移动，`E` 进入附近地点，`M` 回地图；点击地图或六个地点按钮自动寻路；可切换全城 / 放大跟随视角。
- `A / D` 或左右方向键：打捞时换航道；`Space`：打捞、确认酿造、收杯。
- `1 / 2 / 3`：选顾客；`E`：开始倒酒。
- `P / Esc`：暂停；`H`：帮助。事件必须点击选项，不会因按 Esc 自动作出决定。
- 页面上的按钮涵盖全部操作，适配窄屏。
- 进度存于 `ab_reopening_v1`，包括酿造阶段内计时、城市位置与发现地点。刷新会停止未走完的路线，但保留位置；旧存档没有城市信息时，从酒吧门口开始。切到后台和刷新后会暂停，恢复后继续。
- 暂停菜单可以重开；结束页可以用相同顾客安排重试或换种子。
- 新入口与旧七天版存档键独立。无法读取或格式不符的试玩存档会提示并新开一局。

## 代码与验证

- `reopening-city.js`：城市地形、建筑碰撞、桥/渡轮通路、自动寻路、步行和独立地图存档验证。
- `reopening-core.js`：可在 Node 测试的不可变状态转移、种子生成、库存、事件与存档验证。
- `reopening-ui.js`：页面交互、暂停、存档、音效、键盘、教学及计时。
- `reopening-scene.js`：随库存、顾客、酒杯、打捞航道与升级变化的 Canvas 场景。
- `reopening.css`：响应式布局和操作界面。

```sh
node --test tools/prototype/test-reopening.js tools/prototype/test-city.js
node tools/prototype/test-phase-e.js
node --check tools/prototype/reopening-ui.js
node --check tools/prototype/reopening-scene.js
```

新规则测试覆盖完整三天获胜与失败、资源消耗、留酒承诺、设备取舍、事件成本与暂停、打捞收益/失误/靠岸、种子确定性及非法存档。第二条命令验收旧版 Phase E 规则。

手动验收：进入打捞并捕获物品 → 酿一批 → 夜晚成功收杯 → 应对事件 → 刷新确认暂停恢复 → 结算选升级 → 走完第三晚 → 重开；同时检查窄屏按钮和控制台错误。
