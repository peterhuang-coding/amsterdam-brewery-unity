# Tweede Kans · 三天重开试玩

默认 `index.html` 是新的三天经营切片。白天出去折腾、晚上开店，黑色幽默通过真实成本和后果发生：房东喝酒抵租，网红用免费样品换预算更高的客流，检查员的表格也有处理费。

## 城市背面探险（夜探 2 · 2026-09-16）

欢迎页点「开始这一天，出门逛逛」。在酒馆营业并打烊后，点「带上工具，开始夜间探险」。可以提前收店，也可跳过探险直接睡觉。每夜一次，不占白天准备机会；先选长钩绳、搬货背架或泡沫工具，分别改变射程、容量、步速或泡沫恢复速度。原三天经营、旧打捞和其他白天行动仍可使用。

一张连续的 2200×1400 行动地图连接超市后场、红灯运河街、NO SIGNAL 夜店、失物分拣场和温室。走动、钩取、泡沫、闪避在所有区域使用同一规则。滚桶、机器冲撞、巡查者、人群和叼零件的鸟会改变取得物品的过程；相同种子/日/工具/输入可复现，种子与日期改变部分物资位置、运动方向及巡回初始条件。

默认使用 **自动探索 + 关键选择**：点击行动或按对应数字键 `1–9`，角色会真正走到目的地、收集和使用工具；拿箱、交还 Noor、开温室前暂停等你决定。阅读选项时，人物、物品、冷却和倒计时全部暂停。「选择路线，开始探索」定位到待选路线；选路线即开始行动，行进时按钮变成「暂停探索」。速度 `1× / 2×` 独立设置；途中也可「停下来，重新选路」。容量不足时逐件选择放下什么。已交还的箱子不再显示成领取目标。

旧存档刷新后可点「切换自动探索」；新一趟默认启用。随时切换手动操作，切回自动时重新选路线，已有物品、发现与时间保留。未走完的自动目的地或待选事件随探险一起保存。夜店新增两种取箱选择：消耗一只空瓶把守卫引向声源，或先把路边空桶拖到后门、放下，再绕行拿箱。保留泡沫和钩取；这些策略通过真实移动与工具执行。以下为手动操作及两种模式共用规则：

- `WASD` / 方向键移动；鼠标瞄准，左键或 `J` 钩拉，右键或 `F` 泡沫；`Space` 朝瞄准方向闪避。鼠标离开画布后，纯键盘操作朝行走方向使用工具。
- `N` 投空瓶：每趟 3 瓶、最远 240、冷却 2 秒，声源持续 5 秒。瓶子在障碍前落地；可看见声源的附近机器/守卫前往调查，贴脸仍有危险。
- `R` 抓住 / 放下带青环的空桶：靠近 65 内且不隔墙，移动速度降至 55%；空桶有实际碰撞，能挡住机器冲撞，也会挡自己。拖桶不能闪避，受外力拉断牵绳会松手。空桶不占背包。
- 普通物资靠近自动装包；`E` 拿冷藏箱、与 Noor 交谈/交付、操作闸门和撤离。`Q` 朝瞄准方向扔下最后一件物品，腾出背包；被撞掉的东西可以追回。
- `M` 全图/跟随镜头；`P` / `Esc` 暂停；`H` 帮助。画面下方方向键可按住，工具和互动都有按钮。
- 180 秒收班。西南入口可随时安全撤回，保留全部背包；温室后门提供第二条安全回家路线。超时或受伤三次保留一半物品件数，主动轻装撤回放弃未交付背包；家中现金和库存不受影响。
- 虚构违禁品“月雾”装在夜店冷藏箱里，需主动拿取，占 3 格。交还红灯街的 Noor 得到 €14 跑腿费，她会在下次营业作为顾客出现；带回箱子则会有打听箱子的人来店。箱子与啤酒、酒花严格分开，不增加酿造材料。
- 温室的维护拉杆可以近身操作或钩拉。实际进入后记录发现，下一天闸门仍打开，可以从后门回到酒馆屋顶。Noor 的经历和箱子处理结果也跨日保留。
- 归来页显示带回内容，点「回酒馆，收好这一趟」一次性入库。刷新保存正在进行的探险并先暂停；旧版三天存档自动补充探险字段，保留原进度。

三晚轮换「夜间补货 / 运河抢修 / 夜店散场」，由种子与日数确定：货堆、施工围挡和排队栏进入真实碰撞，散场人群位置也改变。基础城市布局仍固定，并非程序生成整座城市。旧 version 1 探险迁移为 legacy，正在进行的一趟保留旧街道与位置，下次出门才遇到新局势。

当前是主玩法验证切片；成人题材通过街区、人物和虚构货物表达，尚无毒品使用系统、独立成人服务玩法或完整社会模拟。是否足够耐玩仍需玩家反复试玩判断。

## 三天闭环

白天先从酒吧门口进入城市主地图。七个地点通过运河桥与北岸渡轮连接：Tweede Kans、Lotte 的桥、Bram 咖啡馆、北岸码头、Albert Cuyp 市场、南街花店、Chen 实验室。步行和逛地图免费，点地点自动寻路，到达后打开店铺面板，也可 WASD 自己走并按 E 进入。

自行车在酒馆门口，靠近按 `B` 或按钮上车；骑速420、步速240。窄桥和渡轮前自动下车，车留在入口，可点「去取停好的车」返回；进入店铺也下车。现在没有推车过桥机制。

南街花店可自由进入，不强制玩小游戏。选三枝不同的花和一种包装，完成才花 €4 / 1 次准备，每天最多一束；取消免费。三枝暖色＋丝带送 Lotte 好感 +2，其余 +1；三枝冷色＋牛皮纸摆窗台使客人耐心 +6 秒，其余 +3。花束只能手持、存前篮、送人或陈列；只有在车旁才能取放，不能隔街送出车篮里的花，也不会变成酿酒原料。

打烊后仍能逛同一座城，日间服务关闭并出现夜班留言。探索途中靠近可见搬花工，会暂停询问是否往温室改道；继续保留原目标。次日笔记按发生日记录收获，窗花仍在，Noor 或打听箱子的人会在下次营业出现。深夜收入独立记录，不修改已结算的营业账。

每天两次准备：酿一批酒（€12、6 杯、三段工艺）、替 Bram 打工（赚 €18）、拜访 Lotte（答应留黑啤），或去北岸运河打捞（30 秒或 3 份有用收获）。酒花让下一批品质 +1，密封瓶补充 2 杯库存，单车扣 €2 清运费；捞不到东西也会消耗行动。酒花每批消耗一份。市场另售 €8 的收摊箱（2 杯艾尔 +1 杯黑啤、品质1），实验室售 €6 的两份试验酒花，二者都每天一次、占一次准备。

夜晚选择顾客、核对口味和预算、倒酒并及时收杯。开始倒酒立刻消耗一杯；等待太久、溢杯、错口味和超预算都有后果。无酒时可以送水善后。Lotte 在晚些时候到店；兑现留酒承诺后，下一晚乐队能改善耐心和小费。

每晚营业到第 35 秒会遇到一件暂停事件，阅读后选择：

| 日 | 麻烦 | 选择及代价 |
|---|---|---|
| 1 | 房东的液体押金 | 1 杯酒换租金 −€6；拒绝则租金 +€3 |
| 2 | 曝光量不能交房租 | 2 杯样品换未来 3 位客人预算 +€4；拒绝则这 3 位耐心 −4 秒 |
| 3 | 未发现问题的问题 | €10 手续费换等待及未来客人耐心 +12 秒；延期检查则租金 +€6 |

基础租金 €18，账单展示事件后的实际金额。提前打烊会错过未服务的顾客。前两晚可免费选一件设备：双酒头同时倒两杯；陈酿桶提升隔夜余酒收益；驻唱角增加耐心和小费，但少一个座位。第三晚目标：余额至少 €100、累计 12 位满意顾客。

## 操作与存档

- 城市地图：`WASD` / 方向键移动，`B` 骑车，`E` 进入附近地点，`M` 回地图；点击地图或七个地点按钮自动寻路；可切换全城 / 放大跟随视角，打开景点手册查看夜间笔记。
- `A / D` 或左右方向键：打捞时换航道；`Space`：打捞、确认酿造、收杯。
- `1 / 2 / 3`：选顾客；`E`：开始倒酒。
- `P / Esc`：暂停；`H`：帮助。事件必须点击选项，不会因按 Esc 自动作出决定。
- 页面上的按钮涵盖全部操作，适配窄屏。
- 进度存于 `ab_reopening_v1`，包括酿造阶段内计时、城市位置、自行车、花束与发现地点。刷新会停止未走完的日间路线，但保留位置；旧存档没有城市信息时从酒吧门口开始。被新增花店覆盖的旧站位迁回酒馆，保留访问记录与合法停车位置。旧白天探险存档继续接回原白天。进行中的小游戏和探险切到后台、刷新后会暂停，恢复后继续。
- 暂停菜单可以重开；结束页可以用相同顾客安排重试或换种子。
- 新入口与旧七天版存档键独立。无法读取或格式不符的试玩存档会提示并新开一局。
